# Pizza Shop Data Analysis (SQL)

## Project Overview
This project demonstrates the use of SQL to analyze sales performance and inventory trends. SQL queries were developed using **Joins, Aggregate Functions, GROUP BY, and filtering techniques** to extract meaningful business insights from relational data.

## Objectives
- Analyze sales performance and identify top-performing products.
- Evaluate inventory levels and product availability.
- Combine data from multiple tables using SQL Joins.
- Use aggregate functions to calculate sales metrics and summarize business data.
- Generate insights to support business decision-making.

## Key SQL Skills Demonstrated
- **SQL Joins:** INNER JOIN, LEFT JOIN
- **Aggregate Functions:** SUM(), COUNT(), AVG(), MIN(), MAX()
- **Data Grouping:** GROUP BY and HAVING
- **Data Filtering:** WHERE and ORDER BY
- **Data Analysis:** Sales summaries, product performance, and inventory trends
- **Database Management:** Retrieving and analyzing relational data using MySQL

## Business Use Cases
1. **Sales Performance Analysis:** Analyze total sales and compare product performance.
2. **Product Analysis:** Identify products contributing the most to revenue.
3. **Inventory Analysis:** Examine available inventory and identify products that may require restocking.
4. **Business Reporting:** Transform raw database records into actionable insights using SQL queries.

## Tools & Technologies
- Database: MySQL
- Query Tool: MySQL Workbench
- Version Control: Git and GitHub

## Key Learning Outcomes
- Developed practical SQL querying skills for business analysis.
- Applied Joins and aggregations to analyze data across multiple tables.
- Improved understanding of relational database structures and data-driven decision-making.
